# EventManage

Welcome to **EventManage**, a web application designed to help manage events efficiently. This project is built using modern web technologies and is intended to provide a robust platform for event organization and tracking.

## Overview

EventManage is a public-facing event management system. It aims to simplify event scheduling, attendee management, and resource allocation.

- **Status**: Completed
- **Last Updated**: August 17, 2024

## Features

- User authentication and role-based access
- Event creation and scheduling
- Attendee registration and tracking

## Tech Stack

- **Frontend**: ReactJS, HTML, CSS, JavaScript
- **Backend**: C# (ASP.NET Core)
- **Other Tools**: Entity Framework, SQL Server

## Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Tsutsuji002/EventManage.git
2. **Navigate to the project directory**:
   ```bash
   cd EventManage
3. **Install dependencies**:
   dotnet restore
4. **Run the application**:
   dotnet run
5. **Access the app**:
   Open your browser and go to http://localhost:[port] (check the terminal for the assigned port).

## Usage

Navigate to the 'Events' tab to create a new event, or use the 'Admin' area to manage users.
